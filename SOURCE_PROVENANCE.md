a8975bb1166eb441bb1679618f20a160e583a8b0

EVCycle_v2.0_code.zip, but did not expose the unpacked evcycle package or tests.

- the public repository interface and metadata;
- the R1 and R2 manuscript descriptions;
- the documented MockRouter, validation, export, and uncertainty interfaces.

The revised target repository is:

https://github.com/Meqdad82/EVCycle2

commit as the source of this reconstructed tree. Update the manuscript code
